## Rules
- For NEW functions/files/feature flags → type: FEAT
- For bug fixes → type: FIX
- For refactoring → type: REFACTOR
- For tests → type: TEST only if the change IS a test file, NOT if adding a function being tested
- For docs/README → type: DOCS

## Format (EXACTLY)
type: description

Previously, what was missing.
Now, what was added.

Example:
feat: add user login function

Previously, users could not log in. Now includes authentication.
