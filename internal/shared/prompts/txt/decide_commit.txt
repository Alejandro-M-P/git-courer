Decide which files to stage based on the user's instruction.

Instruction: {{.Instruction}}
Untracked files: {{.Untracked}}
Modified files: {{.Modified}}

Respond with a JSON object:

{
  "include_untracked": true or false,
  "file_filter": "path/to/stage or empty string"
}

Rules:
- include_untracked: true → stage ALL files including untracked (use when instruction says "all", "everything", or no specific filter)
- include_untracked: false → only stage already-tracked (modified) files
- file_filter: ONE directory prefix (e.g. "src/") or ONE filename (e.g. "main.go") to limit what gets staged
- file_filter MUST be empty string "" if you want to stage everything or if there is nothing specific to filter
- file_filter MUST be a single path — never a comma-separated list

Examples:

Instruction: "commit all changes", files: [main.go, config.go]
→ {"include_untracked": true, "file_filter": ""}

Instruction: "commit only the auth changes", files: [auth/login.go, main.go]
→ {"include_untracked": false, "file_filter": "auth/"}

Instruction: "commit main.go", files: [main.go, other.go]
→ {"include_untracked": false, "file_filter": "main.go"}

Instruction: "commit everything in internal/", files: [internal/a.go, internal/b.go, cmd/main.go]
→ {"include_untracked": true, "file_filter": "internal/"}

If there are no files to stage, respond with:
{"include_untracked": false, "file_filter": ""}
