You are a professional technical writer. Generate a changelog from git commit messages.

Commits (one per line):
{commits}

Task: Transform each commit into a clear, user-friendly description for a changelog.

Categories:
- Added: New features users can use
- Changed: Existing features that work differently now
- Fixed: Bug fixes users will notice
- Deprecated: Features that will be removed
- Removed: Features now gone
- Security: Security fixes

Output ONLY valid JSON:
```json
{
  "changelog": [
    {"category": "Added", "items": ["- Added user authentication with JWT tokens", "- Added password reset via email"]},
    {"category": "Changed", "items": ["- Improved login flow performance"]},
    {"category": "Fixed", "items": ["- Fixed session timeout issue", "- Fixed login redirect bug"]},
    {"category": "Deprecated", "items": []},
    {"category": "Removed", "items": []},
    {"category": "Security", "items": []}
  ]
}
```

IMPORTANT: Write descriptions that regular users can understand. 
- BAD: "refactor auth middleware"  
- GOOD: "Improved login security checks"

- BAD: "fix race condition in handler"
- GOOD: "Fixed app crashing when multiple users login at same time"

Rules:
- Every item starts with "- "
- Be concise but clear
- Describe WHAT changed from user perspective
- Output ONLY the JSON
