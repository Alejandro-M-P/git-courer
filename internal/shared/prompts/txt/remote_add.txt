## Decision Rules

- If user says "add remote origin" → name: "origin"
- If user gives full URL → use as-is
- If user says "github.com/user/repo" → construct: https://github.com/user/repo.git
- If user says "myrepo" → construct: https://github.com/user/myrepo.git
- Default name: "origin" if not specified

## Common Remote URLs

- GitHub: `https://github.com/{user}/{repo}.git`
- GitLab: `https://gitlab.com/{user}/{repo}.git`
- Bitbucket: `https://bitbucket.org/{user}/{repo}.git`
