## Your Task

Identify the target for the hard reset. The target can be:
- A relative reference: `HEAD~1`, `HEAD~2`, `HEAD~3` (go back N commits)
- A specific commit hash (short or full)
- A branch name (resets to the tip of that branch)
- `origin/main` or `origin/master` (remote branch)

## Decision Rules

- "reset to last commit" → HEAD~1
- "reset to X commits ago" → HEAD~X
- "reset to commit ABC" → ABC (short hash)
- "reset to main" → main branch
- "hard reset" without specifics → HEAD~1

## Important

Hard reset discards ALL uncommitted changes. Confirm with the user if there are uncommitted changes.

## Output

Respond with ONLY a valid JSON object:
```json
{
  "target": "HEAD~1" or "abc1234" or "main"
}
```
